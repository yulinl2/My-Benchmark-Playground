# Question bank

The curated, machine-readable heart of the repo.

- **`schema.json`** — JSON Schema (draft-07 subset) every question must satisfy.
- **`questions/`** — one JSON file per exam, each a JSON **array** of question
  objects. This is the source of truth you edit.
- **`bank.jsonl`** — generated by `scripts/build_bank.py`; all curated questions
  concatenated, one JSON object per line. **Do not edit by hand.**
- **`questions/_example.json`** — a synthetic illustrative entry (filename starts
  with `_`, so it's validated but kept out of `bank.jsonl`). Delete once you have
  real transcriptions.

## A question entry

```json
{
  "id": "2019-fall-probability-q3",
  "exam": { "year": 2019, "term": "fall", "part": "probability" },
  "number": 3,
  "topics": ["convergence", "CLT"],
  "difficulty": "medium",
  "prompt": "Let $X_1,\\dots,X_n$ be i.i.d. ... (Markdown + LaTeX)",
  "parts": ["(a) ...", "(b) ..."],
  "solution": "Optional worked solution, or null.",
  "source": { "pdf": "2019_fall_probability.pdf", "page": 1 },
  "verified": false,
  "notes": ""
}
```

### Conventions

- **`id`**: `<year>-<term>-<part>-q<number>`, lowercase. Append a letter for
  split parts if needed (e.g. `...-q3a`). Must be unique across the whole bank.
- **`part`**: one of `probability`, `math-stat`, `applied`, `other`.
- **`prompt`/`solution`**: Markdown with LaTeX in `$...$` / `$$...$$`.
- **`verified`**: set to `true` only after a human checks the transcription
  against the source PDF.

Build/validate after any edit:

```bash
python scripts/build_bank.py          # validate + rebuild bank.jsonl + stats
python scripts/build_bank.py --check  # validate only (good for CI)
```
