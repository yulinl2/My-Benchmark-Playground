# Raw exam PDFs

Drop the PhD qual exam and solution PDFs you download from the Rutgers
SharePoint repo here.

**Suggested naming:** `<year>_<term>_<part>.pdf`, e.g.

```
2019_fall_probability.pdf
2019_fall_mathstat.pdf
2019_fall_applied.pdf
2019_fall_probability_solutions.pdf
```

> The PDFs themselves are **git-ignored by default** (see the repo's
> `.gitignore`) so the original copyrighted files aren't pushed to GitHub.
> Only the transcriptions and curated question entries are tracked. If you
> intentionally want to commit a PDF, force-add it with `git add -f`.
